# Database Rules — PostgreSQL Schema

## Nguyên tắc cơ bản

- Database duy nhất: **PostgreSQL**
- ORM: **Entity Framework Core** (migrations tự động generate schema)
- File `database.sql` là **tài liệu tham khảo** — nguồn thật là EF Core Migrations
- File `DATABASE_SUMMARY.txt` là **cheatsheet** cho developer, luôn sync với schema thực tế

---

## Quy tắc: Khi thay đổi schema

### LUÔN thay đổi theo thứ tự này (không được bỏ bước nào):

```
Bước 1: Sửa Entity class
        → backend/SocialNetwork.Api/Entities/*.cs

Bước 2: Cập nhật DbContext nếu có relation mới
        → backend/SocialNetwork.Api/Data/SocialDbContext.cs

Bước 3: Tạo Migration (KHÔNG sửa tay file migration)
        → cd backend/SocialNetwork.Api
        → dotnet ef migrations add <TênMigration>
        → Xem lại file migration được generate để đảm bảo đúng

Bước 4: Áp dụng Migration lên database
        → dotnet ef database update

Bước 5: Cập nhật database/database.sql
        → Nếu thêm cột: thêm ALTER TABLE hoặc sửa CREATE TABLE
        → Nếu thêm bảng: thêm CREATE TABLE mới + CREATE INDEX phù hợp
        → Nếu xóa cột: thêm ALTER TABLE DROP COLUMN (và ghi chú version)

Bước 6: Cập nhật database/DATABASE_SUMMARY.txt
        → Thêm/sửa mô tả column/table tương ứng

Bước 7: Cập nhật DTO
        → backend/SocialNetwork.Api/DTOs/

Bước 8: Cập nhật TypeScript type
        → frontend/src/types/api.types.ts
```

## Quy tắc đặt tên trong PostgreSQL (snake_case)

```sql
-- ✅ Đúng — snake_case cho tất cả
CREATE TABLE conversation_participants (
    conversation_id INTEGER,
    user_id         INTEGER,
    created_at      TIMESTAMPTZ
);

-- ❌ Sai — PascalCase hay camelCase
CREATE TABLE ConversationParticipants (
    ConversationId INTEGER,
    userId INTEGER
);
```

**EF Core mapping:** EF Core tự map `PascalCase` C# property → `snake_case` PostgreSQL column thông qua Npgsql convention. Không cần `[Column("snake_case")]` annotation thủ công.

## Quy tắc columns

### Timestamps
```sql
-- ✅ Luôn dùng TIMESTAMPTZ (timezone-aware), KHÔNG dùng TIMESTAMP
created_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
updated_at TIMESTAMPTZ NOT NULL DEFAULT NOW()
```

### NOT NULL
```sql
-- ✅ Tất cả required fields phải có NOT NULL
username VARCHAR(50) UNIQUE NOT NULL,
content  TEXT        NOT NULL,

-- Chỉ nullable nếu thực sự optional
image_url TEXT,           -- nullable vì post không bắt buộc có ảnh
parent_id INTEGER,        -- nullable vì top-level comment không có parent
```

### Foreign Keys
```sql
-- ✅ Luôn có ON DELETE CASCADE hoặc ON DELETE SET NULL (chọn phù hợp)
user_id INTEGER NOT NULL REFERENCES users(id) ON DELETE CASCADE,

-- Dùng ON DELETE CASCADE khi: xóa user → xóa hết posts, comments, ...
-- Dùng ON DELETE SET NULL khi: muốn giữ lại record nhưng bỏ reference
```

### Constraint naming
```sql
-- ✅ Đặt tên constraint explicit để dễ debug
PRIMARY KEY (follower_id, following_id),
CONSTRAINT no_self_follow CHECK (follower_id <> following_id)

-- ❌ Constraint không tên sẽ khó identify khi bị lỗi
CHECK (follower_id <> following_id)
```

## Quy tắc Indexes

Luôn thêm index cho:
1. **Foreign key columns** (EF Core tự làm với Migrations nhưng thêm vào `database.sql` để tham khảo)
2. **Columns thường dùng trong WHERE/ORDER BY**
3. **Columns dùng để search** (`username`, `full_name`)

```sql
-- Pattern: idx_{table}_{column(s)}
CREATE INDEX idx_posts_user_id    ON posts(user_id);
CREATE INDEX idx_posts_created_at ON posts(created_at DESC);  -- ORDER BY thường dùng DESC

-- Composite index khi query cả 2 cột cùng lúc
CREATE INDEX idx_notifications_unread ON notifications(user_id, is_read);
```

## Bảng hiện có và mục đích

| Bảng | Mục đích | Cột đặc biệt |
|---|---|---|
| `users` | Tài khoản người dùng | `role` = 'Member'/'Admin', `password_hash` chỉ lưu BCrypt |
| `posts` | Bài viết | `image_url` nullable |
| `comments` | Bình luận + Reply | `parent_id` NULL = top-level comment |
| `post_likes` | Like bài viết | Composite PK `(user_id, post_id)` |
| `follows` | Quan hệ follow | Self-ref, CHECK `follower_id <> following_id` |
| `conversations` | Phòng chat | Chỉ có `id` + `created_at` |
| `conversation_participants` | Ai trong phòng chat | Composite PK `(conversation_id, user_id)` |
| `messages` | Tin nhắn | `is_read` track trạng thái |
| `notifications` | Thông báo | `entity_id` không có FK (trỏ post hoặc comment) |

## Không làm những điều này

```sql
-- ❌ Không sửa file Migration đã apply
-- File trong Migrations/ sau khi đã chạy dotnet ef database update là readonly

-- ❌ Không drop-recreate database để fix lỗi migration trong production
-- Luôn tạo migration mới để sửa

-- ❌ Không dùng TIMESTAMP thay TIMESTAMPTZ
created_at TIMESTAMP  -- ❌ thiếu timezone
created_at TIMESTAMPTZ -- ✅

-- ❌ Không dùng VARCHAR quá nhỏ cho text content
content VARCHAR(255)  -- ❌ posts có thể dài hơn
content TEXT          -- ✅

-- ❌ Không hardcode enum values vào CHECK constraint nếu list có thể thay đổi
-- notification_type VARCHAR(20) với CHECK IN ('like','comment','follow')
-- Thay vào đó document ở tầng application (enum trong C#)
```

## Khi thêm bảng mới — checklist đầy đủ

```
□ Tạo Entity class        → backend/Entities/NewTable.cs
□ Thêm DbSet              → Data/SocialDbContext.cs
□ Cấu hình relationships  → SocialDbContext.OnModelCreating()
□ Tạo migration           → dotnet ef migrations add Add<NewTable>
□ Review migration file   → đảm bảo indexes, constraints đúng
□ Apply migration         → dotnet ef database update
□ Cập nhật database.sql   → CREATE TABLE + CREATE INDEX
□ Cập nhật DATABASE_SUMMARY.txt → mô tả bảng mới
□ Tạo DTOs tương ứng      → backend/DTOs/
□ Cập nhật TypeScript     → frontend/src/types/api.types.ts
□ Cập nhật FEATURES.md
```

## Ví dụ: Thêm tính năng Bookmark

**Yêu cầu:** User có thể lưu bài viết vào Bookmarks

**Các file cần thay đổi:**

```
1. backend/Entities/Bookmark.cs           ← Entity mới
2. backend/Data/SocialDbContext.cs        ← Thêm DbSet<Bookmark>
3. dotnet ef migrations add AddBookmarks  ← Migration
4. database/database.sql                  ← Thêm CREATE TABLE bookmarks
5. database/DATABASE_SUMMARY.txt          ← Mô tả bảng bookmarks
6. backend/DTOs/Post/PostDtos.cs          ← PostDto thêm IsBookmarked boolean
7. backend/Services/Interfaces/IPostService.cs    ← Thêm ToggleBookmarkAsync
8. backend/Services/Implementations/PostService.cs ← Implement
9. backend/Controllers/PostsController.cs  ← Thêm POST /api/posts/{id}/bookmark
10. frontend/src/types/api.types.ts        ← PostDto thêm isBookmarked: boolean
11. frontend/src/api/postsApi.ts           ← Thêm bookmarkPost()
12. frontend/src/components/feed/PostCard.tsx ← Thêm BookmarkButton
13. FEATURES.md                           ← Cập nhật trạng thái Bookmarks ✅
```
