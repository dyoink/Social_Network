# Backend Rules — ASP.NET Core API

## Architecture: Controller → Service → DbContext

### Controller
- **Chỉ xử lý HTTP:** nhận request, validate, gọi Service, trả response
- **Không có business logic** trong Controller
- **Luôn trả về `ApiResponse<T>`** — không trả raw object
- Route convention: `api/[controller]` (lowercase, plural)

```csharp
// ✅ Đúng
[HttpGet("{id}")]
[Authorize]
public async Task<ActionResult<ApiResponse<PostDto>>> GetPost(int id)
{
    var result = await _postService.GetByIdAsync(id, CurrentUserId);
    if (result is null) return NotFound(ApiResponse<PostDto>.Fail("Không tìm thấy bài viết"));
    return Ok(ApiResponse<PostDto>.Ok(result));
}

// ❌ Sai — logic trong Controller, không dùng ApiResponse
[HttpGet("{id}")]
public async Task<Post> GetPost(int id)
{
    return await _context.Posts.FindAsync(id); // trả raw Entity
}
```

### Service Interface & Implementation
- **Mỗi tính năng = 1 Interface + 1 Implementation**
- Interface nằm ở `Services/Interfaces/I{Name}Service.cs`
- Implementation nằm ở `Services/Implementations/{Name}Service.cs`
- Service inject `SocialDbContext` và `ILogger<T>`, KHÔNG inject Controller hay HttpContext
- Để lấy UserId trong Controller: `int CurrentUserId => int.Parse(User.FindFirst(ClaimTypes.NameIdentifier)!.Value);`

```csharp
// ✅ Đúng — Service nhận userId làm parameter
public async Task<PostDto?> GetByIdAsync(int postId, int currentUserId)
{
    var post = await _context.Posts
        .Include(p => p.User)
        .FirstOrDefaultAsync(p => p.Id == postId);
    // map to DTO...
}

// ❌ Sai — Service tự truy cập HttpContext
public async Task<PostDto?> GetByIdAsync(int postId)
{
    var userId = _httpContextAccessor.HttpContext!.User...; // không làm thế này
}
```

### DTO Rules
- **KHÔNG trả Entity trực tiếp** từ API — luôn map sang DTO
- `UserDto` (full info) vs `UserSummaryDto` (id, username, avatarUrl): dùng Summary khi embed trong PostDto, CommentDto
- Timestamps trong DTO luôn là `DateTime` (serialize thành ISO 8601)
- Nullable field dùng `?`, không dùng empty string thay cho null

```csharp
// ✅ Đúng — DTO, không expose Entity
public class PostDto
{
    public int Id { get; set; }
    public UserSummaryDto User { get; set; } = null!;
    public string Content { get; set; } = string.Empty;
    public string? ImageUrl { get; set; }   // nullable dùng ?
    public DateTime CreatedAt { get; set; }
    public int LikesCount { get; set; }
    public bool IsLiked { get; set; }       // computed cho current user
}

// ❌ Sai — trả Entity, lộ PasswordHash và circular reference
public class PostController
{
    public Post GetPost() => _context.Posts.Find(id);
}
```

### Authentication & Authorization
- Endpoint nào cần auth → thêm `[Authorize]`
- Endpoint nào public → thêm `[AllowAnonymous]` (explicit)
- **Luôn verify ownership** trước khi cho phép sửa/xóa:

```csharp
// ✅ Luôn kiểm tra ownership
var post = await _context.Posts.FindAsync(id);
if (post is null) return NotFound(...);
if (post.UserId != currentUserId) return Forbid();
```

- JWT claims để lấy userId: `ClaimTypes.NameIdentifier`
- JWT claims để lấy role: `ClaimTypes.Role`

### EF Core Queries
- Dùng `AsNoTracking()` cho read-only queries (GET endpoints)
- Dùng `Include()` để eager load, tránh N+1 queries
- Dùng `Select()` thay vì load toàn bộ Entity rồi map

```csharp
// ✅ Hiệu quả — chỉ select những gì cần
var posts = await _context.Posts
    .AsNoTracking()
    .Where(p => followingIds.Contains(p.UserId))
    .OrderByDescending(p => p.CreatedAt)
    .Select(p => new PostDto
    {
        Id = p.Id,
        Content = p.Content,
        LikesCount = p.Likes.Count,
        IsLiked = p.Likes.Any(l => l.UserId == currentUserId)
    })
    .Skip((page - 1) * pageSize)
    .Take(pageSize)
    .ToListAsync();

// ❌ Load all rồi map trong memory — tệ với data lớn
var posts = await _context.Posts.Include(p => p.Likes).ToListAsync();
var dtos = posts.Select(p => new PostDto { ... }).ToList();
```

### Password & Security
- **Chỉ dùng BCrypt** để hash password — KHÔNG dùng MD5, SHA1, SHA256 plain
- Verify: `BCrypt.Net.BCrypt.Verify(plainPassword, passwordHash)`
- Hash: `BCrypt.Net.BCrypt.HashPassword(password, workFactor: 12)`
- **KHÔNG log password, token** dù ở bất kỳ level nào

### Pagination — tất cả list endpoint

```csharp
// Query params: ?page=1&pageSize=10
// Trả về PagedResult<T>, không trả List<T> thẳng

public class PagedResult<T>
{
    public List<T> Items { get; set; } = new();
    public int TotalCount { get; set; }
    public int Page { get; set; }
    public int PageSize { get; set; }
    public bool HasNextPage => Page * PageSize < TotalCount;
}
```

### Error Handling
- Không dùng try/catch trong mọi Controller action — đã có `GlobalExceptionMiddleware`
- Chỉ catch exception khi cần xử lý cụ thể (ví dụ: unique constraint violation)
- HTTP status codes phải đúng ngữ nghĩa:
  - `200 OK` — thành công
  - `201 Created` — tạo mới thành công (POST)
  - `400 Bad Request` — input không hợp lệ
  - `401 Unauthorized` — chưa đăng nhập
  - `403 Forbidden` — không có quyền
  - `404 Not Found` — không tìm thấy resource

### Naming Conventions

```csharp
// Class: PascalCase
public class PostService { }

// Interface: I + PascalCase
public interface IPostService { }

// Async method: suffix Async
public async Task<PostDto> GetByIdAsync(int id) { }

// Private field: _camelCase
private readonly SocialDbContext _context;
private readonly ILogger<PostService> _logger;

// Constants: UPPER_SNAKE_CASE
private const int MAX_FILE_SIZE_MB = 10;
```

### Khi thêm tính năng mới — checklist

```
□ Thêm method vào Interface (I*Service.cs)
□ Implement trong Service
□ Thêm action vào Controller với [Authorize] nếu cần
□ Thêm/sửa DTO nếu request/response thay đổi
□ Đăng ký Service mới trong Extensions/ServiceCollectionExtensions.cs
□ Cập nhật BACKEND_PLAN.md (đánh dấu checklist)
□ Cập nhật FEATURES.md
```

### Khi thêm/sửa Entity — checklist

```
□ Sửa Entity class trong Entities/
□ Cập nhật cấu hình trong SocialDbContext.OnModelCreating() nếu có relation mới
□ dotnet ef migrations add <TênMigration>
□ Xem lại migration file được generate (Migrations/) — đảm bảo đúng
□ dotnet ef database update
□ Cập nhật database/database.sql (thêm ALTER TABLE hoặc sửa CREATE TABLE)
□ Cập nhật database/DATABASE_SUMMARY.txt
□ Cập nhật DTO tương ứng
□ Cập nhật frontend/src/types/api.types.ts
```
