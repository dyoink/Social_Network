# Frontend Rules — React + TypeScript

## Architecture: Component → API call → Zustand Store

### 1. Luôn dùng `axios` instance từ `src/api/axios.ts`

```typescript
// ✅ Đúng — dùng instance có interceptor
import api from '../api/axios';
const res = await api.get<ApiResponse<PostDto>>('/posts/feed');

// ❌ Sai — fetch thẳng, không có JWT attached
const res = await fetch('http://localhost:5000/api/posts/feed');
```

### 2. Tổ chức API files — 1 file per domain

```
src/api/
├── axios.ts          ← instance + interceptors (KHÔNG sửa nếu không cần thiết)
├── authApi.ts        ← register, login
├── postsApi.ts       ← getFeed, createPost, likePost, getUserPosts
├── usersApi.ts       ← getProfile, updateProfile, toggleFollow, search
├── commentsApi.ts    ← getComments, createComment, deleteComment
├── messagesApi.ts    ← getConversations, createConversation, getMessages, sendMessage
└── notificationsApi.ts ← getAll, markRead, markAllRead
```

```typescript
// ✅ Cấu trúc 1 api file
// src/api/postsApi.ts
import api from './axios';
import type { ApiResponse, PagedResult, PostDto, CreatePostDto } from '../types/api.types';

const postsApi = {
  getFeed: (page = 1, pageSize = 10) =>
    api.get<ApiResponse<PagedResult<PostDto>>>(`/posts/feed?page=${page}&pageSize=${pageSize}`),

  createPost: (data: CreatePostDto) =>
    api.post<ApiResponse<PostDto>>('/posts', data),

  likePost: (postId: number) =>
    api.post<ApiResponse<void>>(`/posts/${postId}/like`),
};

export default postsApi;
```

### 3. TypeScript Types phải khớp với Backend DTOs

**QUAN TRỌNG:** IDs luôn là `number`, KHÔNG phải `string`.

```typescript
// src/types/api.types.ts — luôn đồng bộ với backend DTOs

// ✅ Đúng
export interface UserSummaryDto {
  id: number;           // int từ backend
  username: string;
  fullName?: string | null;
  avatarUrl?: string | null;
}

export interface PostDto {
  id: number;           // int, không phải string
  user: UserSummaryDto;
  content: string;
  imageUrl?: string | null;
  createdAt: string;    // ISO 8601 string
  likesCount: number;
  commentsCount: number;
  isLiked: boolean;
}

// ❌ Sai — id: string sẽ gây lỗi khi so sánh với API data
export interface Post {
  id: string;
  author: { id: string; name: string; }
}
```

**Khi backend thêm field mới:**
1. Cập nhật type trong `src/types/api.types.ts`
2. Kiểm tra tất cả nơi dùng type đó — TypeScript sẽ báo lỗi compile nếu dùng sai

### 4. State Management với Zustand

```typescript
// src/store/authStore.ts — pattern chuẩn
import { create } from 'zustand';
import { persist } from 'zustand/middleware';

interface AuthState {
  user: UserDto | null;
  accessToken: string | null;
  isAuthenticated: boolean;
  // actions
  setAuth: (user: UserDto, token: string) => void;
  logout: () => void;
}

export const useAuthStore = create<AuthState>()(
  persist(
    (set) => ({
      user: null,
      accessToken: null,
      isAuthenticated: false,
      setAuth: (user, accessToken) => set({ user, accessToken, isAuthenticated: true }),
      logout: () => set({ user: null, accessToken: null, isAuthenticated: false }),
    }),
    { name: 'auth-storage' }
  )
);
```

**Khi nào dùng Zustand, khi nào dùng local state:**
- **Zustand:** auth user, notifications, conversations (cần share giữa nhiều component)
- **Local state (`useState`):** form inputs, UI toggles, data chỉ dùng trong 1 component

### 6. Error Handling — hiển thị lỗi cho user

```typescript
// ✅ Luôn catch lỗi và hiện toast
const handleLike = async (postId: number) => {
  try {
    await postsApi.likePost(postId);
    // optimistic update đã làm trước đó
  } catch (error) {
    toast.error('Không thể thích bài viết. Vui lòng thử lại.');
    // rollback optimistic update
  }
};

// ❌ Không catch, user không biết có lỗi
const handleLike = async (postId: number) => {
  await postsApi.likePost(postId);
};
```

### 7. Optimistic Updates cho UX mượt

```typescript
// Like/Unlike — cập nhật UI trước, rollback nếu API fail
const handleLike = async (postId: number) => {
  // 1. Lưu state cũ để rollback
  const previousPosts = posts;

  // 2. Cập nhật UI ngay (optimistic)
  setPosts(prev => prev.map(p =>
    p.id === postId
      ? { ...p, isLiked: !p.isLiked, likesCount: p.isLiked ? p.likesCount - 1 : p.likesCount + 1 }
      : p
  ));

  try {
    await postsApi.likePost(postId);
  } catch {
    // 3. Rollback nếu fail
    setPosts(previousPosts);
    toast.error('Có lỗi xảy ra');
  }
};
```

### 8. Loading & Skeleton States

- Mọi component fetch data đều phải có loading state
- Dùng skeleton thay vì spinner cho content areas lớn
- Spinner chỉ dùng cho actions (button submit, v.v.)

```tsx
// ✅ Skeleton cho content
if (isLoading) return <PostCardSkeleton />;
if (error) return <ErrorMessage message="Không thể tải bài viết" />;
return <PostCard post={post} />;
```

### 11. Naming Conventions

```typescript
// Components: PascalCase
const PostCard = () => {};

```

### 12. TailwindCSS

- KHÔNG viết inline `style={{}}` — dùng Tailwind classes
- KHÔNG dùng CSS modules hay styled-components
- Dùng design tokens đã có: `text-on-surface`, `bg-surface-container`, `text-primary`, v.v.
- Responsive: mobile-first, dùng `md:`, `lg:` prefix

```tsx
// ✅ Tailwind
<div className="bg-surface-container-lowest rounded-xl p-6 shadow-sm">

// ❌ Inline style
<div style={{ backgroundColor: '#fff', borderRadius: '12px', padding: '24px' }}>
```
